# Octobre Rose — site en six pages

- index.html : accueil et accès aux rubriques
- comprendre.html : sensibilisation, signes, soutien à une proche et quiz facultatif
- cancers.html : présentation de cinq cancers et ressources
- soutien.html : mur, formulaire et engagement
- rencontres.html : conférences, détails à confirmer
- services.html : services AMMGROUP DIGITAL et réalisations

Ouvrez index.html pour commencer. Pour la publication GitHub Pages, copiez tout le contenu dans le dossier du site : les six pages HTML, les fichiers CSS et JavaScript, config.js et assets/. Gardez tous ces fichiers ensemble.

La configuration publique Supabase validée est conservée. Aucun envoi de test effectué à la base. Syntaxe JavaScript, fichiers locaux et liens entre pages vérifiés. L’affichage visuel dans un navigateur reste à confirmer. Cette archive n’a pas été publiée en ligne.
